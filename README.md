# Assignment Description and Goals

Learn to use GitHub to manage your code.
Understand the C++ program structure (#include, main()).
Practice basic output using cout.
Learn to compile and run your program using make.
Add and test your own simple code inside main().

## Build Instructions

**Ensure that you have a C++ compiler installed.**

### 1. Clone the repository

git clone https://github.com/your-username/your-repository.git

Note: Replace https://github.com/your-username/your-repository.git with the repository URL you received when accepting the assignment.

2. Navigate to the project directory

cd your-repository
Note: Replace your-repository with the actual repository name.

3. Write your code and test it throughout

Make the required code changes (typically indicated by comments like // Your code here).

Test your code regularly to ensure your logic is correct.

4. Run your code

make run

5. Commit and push your changes

git add .
git commit -m "Description of changes"
git push


Note: Use a meaningful commit message describing your changes.

6. Clean up build artifacts
make clean

Testing Your Code
1. Run the tests
make test

2. Verify all tests pass

Your code should pass all unit tests.
You should see:

All tests passed


If not, update your code until all tests pass successfully.
